# 🧠 TDAH Dashboard

- **Repo**: https://github.com/cuervoc-openclaw/TDAH-DASHBOARD
- **Local**: workspace/TDAH-DASHBOARD/
- **Estado**: En desarrollo

Dashboard web progresivo (PWA) diseñado para adultos con TDAH.
Desarrollado por 15 agentes autónomos de IA con OpenClaw.

## Stack
- Frontend: React 18 + TypeScript + Tailwind CSS
- Backend: Node.js + Express + Prisma ORM
- Base de datos: SQLite / PostgreSQL
- PWA con instalación en dispositivo
