# Full-Stack Web Optimization SKILL.md

## Purpose
Especializado en proyectos full-stack (PHP/React/Tailwind) con enfoque en optimización técnica + business impact. Creado para David Salas.

## Integration Points
- **Backend**: PHP 8.x, MySQL, Laravel/Symfony
- **Frontend**: React >=18, Tailwind CSS 3.x, Next.js
- **DevOps**: Docker, CI/CD via GitHub Actions
- **Analytics**: GA4, GTM, Search Console
- **Testing**: PHPUnit, Jest + React Testing Library

## Quick Start
```bash
# Activa el agente fullstack
openclaw run fullstack-optimizer --project="./my-project"
```
